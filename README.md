# Twitter-Sentiment-Analysis-using-DL
Using DL RNN Predicting the Sentiment of the Tweet of users

This project is a Streamlit web app that predicts the sentiment of a tweet using a trained Simple RNN (Recurrent Neural Network) model.

The app accepts a text input, preprocesses it using a saved tokenizer, and classifies the sentiment as:

         i. Negative
         ii. Neutral
         iii. Positive
## Project Structure
app.py - Streamlit application

rnn_model.h5 - trained TensorFlow/Keras model

tokenizer.pkl - saved tokenizer used for text preprocessing

requirements.txt - project dependencies

  i. Tech Stack
  
  ii. Python
  
  iii. TensorFlow / Keras
  
  iv. NumPy
  
  v. Streamlit
